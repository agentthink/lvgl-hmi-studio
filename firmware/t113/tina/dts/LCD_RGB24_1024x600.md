# lcd0 节点 1024×600 RGB888 配置方案（SZCLX070H-500-IPS-G-RTP）

> 文档版本：V1.1　|　日期：2026-08-10
> 目标屏：7.0″ IPS 1024×600，**RGB888（24bit）**，DE 模式，50PIN，4 线电阻触摸（独立 FPC）
> 涉及文件：`device/config/chips/t113/configs/mq_r/linux-5.4/board.dts`、`.../mq_r/uboot-board.dts`
> 配套硬件：`docs/hardware/t113-hmi/`（引脚映射与 50PIN 定义见 `02-schematic-spec.md` §6.5）

---

## 0. 双型号固件（型号A 当前硬件 / 型号B 新 HMI 板）

两个型号**同为 1024×600 时序**，仅**接口位宽与触摸类型**不同，已在同一 `board.dts` 内用编译宏实现双型号，互不干扰：

| | 型号 A（当前硬件，默认） | 型号 B（新 HMI 板 SZCLX070H） |
| --- | --- | --- |
| 屏 | 1024×600（rgb18，18bit RGB666） | 1024×600（rgb24，24bit RGB888） |
| 数据引脚 | rgb18（PD0-PD21） | **rgb24（PB2-PB7 + PD0-PD21）** |
| lcd_frm | 1（rgb666 抖动） | 0 |
| lcd_rb_swap | — | 1（D0-D7=蓝 时） |
| 触摸 | 电容 GT911（`&ctp`，event2） | 电阻（`&rtp`，event0） |
| CTP 节点 | enabled | disabled（PB6/PB7 被 rgb24 占用） |

**构建型号切换点（三处，必须一致）：**

| 文件 | 型号 A | 型号 B |
| --- | --- | --- |
| `linux-5.4/board.dts` `HMI_LCD_RGB24` | `0` | `1` |
| `uboot-board.dts` `HMI_LCD_RGB24` | `0` | `1` |
| `app/runtime/runtime_config.h` `HMI_MODEL_B` | `0` | `1` |
| `config/lv_drv_conf.h` `EVDEV_NAME`（由 HMI_MODEL_B 自动） | event2 | event0 |

实现方式：补丁 `patches/0002-t113-mq_r-hmi-rgb24-dual-model.patch`（默认型号 A，当前硬件行为零改动）。
型号 B 构建（build.sh 已封装 MODEL 参数，自动同步翻转 4 处宏）：

```sh
# 位置参数： ./build.sh {config|pkg|all|pack} <TINA_ROOT> B
./build.sh all <TINA_ROOT> B
# 或环境变量： MODEL=B ./build.sh all <TINA_ROOT>
```

> ⚠️ 型号 B 为软件层切换；硬件（新 HMI 板 PCB 走线）必须按 `rgb24_pins_a` 引脚表布线，且背光接 PWM7/PD22、配 TPS65100 偏压（见硬件文档）。

## 1. 现状（无需改动的部分）

`LCD_RGB_1024X600` 编译宏**已经开启**（两处）：

```c
// linux-5.4/board.dts:13  与  uboot-board.dts:7
#define LCD_RGB_1024X600                  1    /* 7寸1024*600 RGB屏 */
#define LCD_RGB_800X480                   0    /* 5寸800*480  RGB屏 */
```

`lcd0` 节点 1024×600 时序参数已就位（与屏规格匹配，dclk≈51.2MHz@60Hz）：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| lcd_x / lcd_y | 1024 / 600 | 分辨率 |
| lcd_dclk_freq | 51 | MHz（1344×635×60≈51.2） |
| lcd_ht / lcd_hbp / lcd_hspw | 1344 / 160 / 20 | 水平：HFP=160（对称） |
| lcd_vt / lcd_vbp / lcd_vspw | 635 / 23 / 3 | 垂直：VFP=12 |
| lcd_hv_sync_polarity | 0 | vs/hs 低有效 |
| lcd_if / lcd_hv_if | 0 / 0 | HV + 并行 RGB |
| lcd_pwm_ch / freq / pol | 7 / 50000 / 1 | **背光 PWM = PWM7（PD22）** |

已使能且匹配新屏的节点（**保持不动**）：
- `&pwm7`（PD22）→ status = "okay"（背光）
- `&rtp`（电阻触摸，T113 内置 TPADC）→ status = "okay"，`allwinner,ts-attached`
- `&sdc0`（TF 卡，PF0-PF5）→ 与 rgb24 无引脚冲突

## 2. 需要修改的内容（已由补丁 `0002-t113-mq_r-hmi-rgb24-dual-model.patch` 实现）

> 以下 diff 均已落入 `board.dts` 的 **`HMI_LCD_RGB24` 型号 B 分支**（默认 0 不生效，型号 A 行为不变）。
> 新环境部署：`cd <TINA_ROOT> && patch -p1 < firmware/t113/tina/dts/patches/0002-....patch`，再按 §0 切宏。

### 2.1 内核 `linux-5.4/board.dts` lcd0（1024×600 分支，约 L1452-1496）

当前用 18bit（rgb18）+ rgb666 抖动，与屏的 RGB888 不符 → 改三处：

```diff
 #if LCD_RGB_1024X600 //1024x600
 &lcd0 {
         // part 1
         lcd_used            = <1>;
         lcd_driver_name     = "default_lcd";
         lcd_backlight       = <50>;

         // part 2
         lcd_if = <0>;
         lcd_hv_if = <0>;

         // part 3
         lcd_x               = <1024>;
         lcd_y               = <600>;
         lcd_width           = <154>;
         lcd_height          = <85>;
         lcd_dclk_freq       = <51>;

         lcd_hbp             = <160>;
         lcd_ht              = <1344>;
         lcd_hspw            = <20>;

         lcd_vbp             = <23>;
         lcd_vt              = <635>;
         lcd_vspw            = <3>;

         lcd_pwm_used        = <1>;
         lcd_pwm_ch          = <7>;
         lcd_pwm_freq        = <50000>;
         lcd_pwm_pol         = <1>;

         // part 5
-        lcd_frm = <1>;                          // rgb666 抖动 → RGB888 关闭
+        lcd_frm = <0>;
+        lcd_rb_swap = <1>;                      // D0-D7=蓝 时置 1（见 §2.3）
         lcd_io_phase = <0x0000>;
         lcd_gamma_en = <0>;
         lcd_cmap_en = <0>;
         lcd_hv_clk_phase = <0>;
         lcd_hv_sync_polarity= <0>;

         // part 6
         lcd_power = "vcc-lcd";
         lcd_pin_power = "vcc-pd";
-        pinctrl-0 = <&rgb18_pins_a>;
-        pinctrl-1 = <&rgb18_pins_b>;
+        pinctrl-0 = <&rgb24_pins_a>;            // 24bit RGB888
+        pinctrl-1 = <&rgb24_pins_b>;
 };
 #endif
```

> `rgb24_pins_a/b` 已在 SoC 基础 dtsi `lichee/linux-5.4/arch/arm/boot/dts/sun8iw20p1.dtsi`（L539/L549）定义，**无需在 board.dts 重复定义**。
> `lcd_rb_swap` 属性驱动支持（`disp2/disp/de/disp_lcd.c` 读取），evb1 板有先例（`lcd_rb_swap = <0>`）。

### 2.2 u-boot `uboot-board.dts`（开机 logo 同样需要 RGB888）

1. **lcd0（1024×600 分支，约 L347-387）**：同样改
   - `pinctrl-0/1`：`rgb18_pins_a/b` → `rgb24_pins_a/b`
   - `lcd_frm = <1>` → `<0>`，加 `lcd_rb_swap = <1>`
2. **删除 `&rgb18_pins_a` / `&rgb18_pins_b` 覆盖（L36-60）**，改为 rgb24 覆盖（u-boot 需要显式指定 28 引脚）：

```c
&rgb24_pins_a {
	allwinner,pins = "PB2", "PB3", "PD0", "PD1", "PD2", "PD3", "PD4", "PD5", \
		"PB4", "PB5", "PD6", "PD7", "PD8", "PD9", "PD10", "PD11", \
		"PB6", "PB7", "PD12", "PD13", "PD14", "PD15", "PD16", "PD17", \
		"PD18", "PD19", "PD20", "PD21";
	allwinner,pname = "PB2", "PB3", "PD0", "PD1", "PD2", "PD3", "PD4", "PD5", \
		"PB4", "PB5", "PD6", "PD7", "PD8", "PD9", "PD10", "PD11", \
		"PB6", "PB7", "PD12", "PD13", "PD14", "PD15", "PD16", "PD17", \
		"PD18", "PD19", "PD20", "PD21";
	allwinner,function = "rgb24";       /* 以 u-boot 引脚复用表为准，备选 "lcd0" */
	allwinner,muxsel = <2>;             /* 与 rgb18 同组复用号，逐脚核对手册 */
	allwinner,drive = <3>;
	allwinner,pull = <0>;
};

&rgb24_pins_b {
	/* 同上 28 引脚 */
	allwinner,function = "rgb24_suspend";
	allwinner,muxsel = <7>;
	allwinner,drive = <1>;
	allwinner,pull = <0>;
};
```

> ⚠️ u-boot 侧 `allwinner,function`/`muxsel` 需对照 u-boot 源码的 t113 引脚复用表（`u-boot/drivers/video/sunxi/...`）逐脚核对——若名称不符，以 u-boot 实际定义为准。

### 2.3 数据位序（屏 B/G/R ↔ D0-D23，二选一）

屏 50PIN 数据排列：**Pin12-19 = B7-B0，Pin20-27 = G7-G0，Pin28-35 = R7-R0**。

sunxi DE 默认输出：D0-D7=红、D8-D15=绿、D16-D23=蓝（`lcd_rb_swap=0`）。

| 方案 | 做法 | lcd_rb_swap |
| --- | --- | --- |
| A（推荐，改软件） | 屏 B 组接 D0-D7、G 组接 D8-D15、R 组接 D16-D23（PCB 按位序 D0→B0 接） | **1** |
| B（改硬件） | 屏 R 组接 D0-D7、B 组接 D16-D23（PCB 按位序 D0→R0 接） | 0 |

> 位序细节：T113 D0=LSB。屏 B7（Pin12）为 MSB → 接 **D7**；B0（Pin19）→ D0。若按“D0→B7”接会出现低 6 位反色的诡异图像，务必按 LSB↔LSB。

### 2.4 禁用电容触摸 CTP（PB6/PB7 冲突）

`rgb24_pins_a` 使用 **PB2-PB7** 作数据线，而 CTP 节点（gt9xxnew_ts）占用：
- `ctp_int_port` = PB6
- `ctp_wakeup` = PB7

新屏为**电阻触摸**（rtp 已使能），且 PB6/PB7 必须让给 LCD 数据 → **禁用 CTP 节点**：

```diff
 &ctp {
+        status = "disabled";
         ctp_name = "gt9xxnew_ts";
         ...
 };
```

或删除整个 `&ctp { ... }` 块（两文件都要处理）。禁用后电阻触摸走 `&rtp`（保持 okay），事件设备为 `/dev/input/event0`。

### 2.5 固件运行时配置（电阻触摸 + 分辨率）

| 文件 | 修改 |
| --- | --- |
| `firmware/t113/app/runtime/runtime_config.h` | `HMI_TOUCH_DEV` = `/dev/input/event0`（电阻）；`HMI_TOUCH_MAX_X/Y` = 触摸**控制器**量程 |
| `firmware/t113/config/lv_drv_conf.h` | `EVDEV_NAME` = `/dev/input/event0` |
| `firmware/t113/app/drivers/touch_evdev.c` | 不再定义量程（改用 `runtime_config.h` 的板级值 + 纯函数 `touch_scale.h`） |
| 编辑器工程 | 屏幕默认分辨率 1024×600（`ScreenDefaultsConfig` / 项目设置） |

> 量程注意：`HMI_TOUCH_MAX_X/Y` 是**触摸控制器上报的坐标范围**，不是 LCD 分辨率。
> 二者混淆会导致屏幕边缘触摸不可达（审查 P0-7：曾按 1024×600 归一，而 WavePI-S6 的
> GT911 按板级 DTS 只上报 0..800/0..480，右侧 224px、底部 120px 点不到）。

## 3. rgb24 引脚映射（供硬件与固件核对）

```
D0=PB2  D1=PB3  D2=PD0  D3=PD1  D4=PD2  D5=PD3  D6=PD4  D7=PD5    ← 蓝（rb_swap=1）
D8=PB4  D9=PB5  D10=PD6 D11=PD7 D12=PD8 D13=PD9 D14=PD10 D15=PD11  ← 绿
D16=PB6 D17=PB7 D18=PD12 D19=PD13 D20=PD14 D21=PD15 D22=PD16 D23=PD17 ← 红
CLK=PD18  DE=PD19  HSYNC=PD20  VSYNC=PD21
背光 PWM=PD22（pwm7）     DVDD=3V3     RESET=GPIO(PE9)+RC
```

> ⚠️ 与旧板（rgb18）不同：24bit 数据**跨 PB2-PB7 + PD0-PD17 两组**，控制脚在 PD18-PD21，无 PD22-PD27 LCD 引脚。新板 PCB 必须按此表走线。

## 4. 编译与验证

```sh
cd <TINA_ROOT>
make -j$(nproc) && pack          # 内核 dts 编译进 dtb，pack 后烧录
# 或仅重编内核后单独部署 dtb：make -j && 更新 boot 分区
```

烧录后验证（串口 115200 控制台）：

```sh
cat /sys/class/disp/disp/attr/sys        # 确认 lcd0 使能、分辨率 1024x600
ls /sys/class/backlight/                 # 应有 backlight 节点（pwm7）
echo 100 > /sys/class/backlight/xxx/brightness   # 背光可调
ls /dev/input/event0                     # 电阻触摸设备（rtp）
cat /sys/class/graphics/fb0/virtual_size # 应为 1024x600
```

显示检查顺序：
1. **纯色屏**（红/绿/蓝/灰）→ 偏色则调 `lcd_rb_swap`（0↔1）或改接线
2. **彩条/字符** → 左右镜像调 SHLR（Pin39，0Ω 接 3V3/GND），上下镜像调 UPDN（Pin40）
3. **花屏/抖动** → 微调 `lcd_dclk_freq`、`lcd_ht/hbp/hspw`、`lcd_vt/vbp/vspw`（以屏厂推荐时序为准）；必要时试 `lcd_hv_clk_phase = <0/1>`
4. **背光不亮** → 确认 pwm7（PD22）使能、`lcd_pwm_pol` 极性、硬件 BL_PWM 接 PD22
5. **无显示** → 先确认 AVDD/VGH/VGL/VCOM 偏压（TPS65100）与 DVDD 3.3V 就位

## 5. 常见问题排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 颜色红蓝互换 | rb_swap 反了 | `lcd_rb_swap` 0↔1 |
| 图像镜像 | 扫描方向脚（SHLR/UPDN）或 DE 极性 | 调 Pin39/40 电平或 `lcd_hv_sync_polarity` |
| 低 6 位数据反色/噪点 | D0-D7 位序接反（LSB/MSB 颠倒） | 按 §2.3 LSB↔LSB 重新接线 |
| 花屏/水波纹 | dclk 或前后肩偏差 | 按屏厂时序表核对 ht/vt/hbp/vbp |
| 背光暗或闪烁 | 极性/频率不匹配 | `lcd_pwm_pol` 0↔1；`lcd_pwm_freq` 50kHz |
| 触摸无反应 | rtp 未使能 或 触摸为 CTP 被禁用 | 确认 `&rtp` okay、HMI_TOUCH_DEV=event0 |
