# 固件字体完整性验证报告

日期：2026-08-08
验证对象：T113-S3 HMI 固件（`out/t113-mq_r/tina_t113-mq_r_uart1.img`，43.99 MB）
参考标准：《现代汉语常用字表》常用字 2500 字（国家语言文字工作委员会，1988）

## 1. 验证范围

固件内集成的 Noto（Source Han Sans SC）CJK 子集字体：

| 字体资源 | 用途 |
|---|---|
| `lv_font_source_han_sans_sc_14_cjk.c` | 运行时 `g_font_cn_14` freetype 失败时的内嵌回退字体 |
| `lv_font_source_han_sans_sc_16_cjk.c` | 运行时 `g_font_cn_16/20` freetype 失败时的内嵌回退字体 |
| `fangsong.ttf`（freetype 加载） | 系统设置 UI 中文主字体 |

## 2. 验证方法

1. 从 `edu.sh.gov.cn`（上海语言文字网）获取《现代汉语常用字表》常用字 2500 字标准字符集。
2. 编写 Python 脚本解析 LVGL 字体 `.c` 源文件中的 `/* U+XXXX */` 字形注释，提取全部码点。
3. 与标准 2500 常用字逐一比对，输出缺失清单。
4. 校验 UI 符号（▼ U+25BC、✓ U+2713、✕ U+2715、FontAwesome 键盘符号）。
5. 用 `fontTools` 校验 `fangsong.ttf` 对设置页实际渲染字符串的覆盖。

## 3. 验证结果（修复前）

### 3.1 内嵌 Noto CJK 子集字体

| 项 | 16px 子集 | 14px 子集 |
|---|---|---|
| 总码点数 | 1433 | 1433 |
| 汉字数 | **1118** | **1118** |
| 2500 常用字覆盖 | **690 / 2500（27.6%）** | **690 / 2500（27.6%）** |
| 缺失常用字 | **1810 个** | **1810 个** |
| ▼ (U+25BC) | 缺失 | 缺失 |
| ✓ (U+2713) | 缺失 | 缺失 |
| ✕ (U+2715) | 缺失 | 缺失 |
| FontAwesome 键盘符号 | 齐全 | 齐全 |

### 3.2 主字体 fangsong.ttf

- 总字形 2699，2500 常用字覆盖 1738 / 2500（69.5%）。
- 设置页实际渲染的中文字符共 211 个，**覆盖 211 / 211（100%）**，无缺失。
- 含 ▼ (U+25BC)、不含 ✓/✕。

### 3.3 根因

- 内嵌 CJK 子集由 lv_font_conv 以一份约 1118 字的 `--symbols` 清单生成，远小于 2500 常用字。
- 该子集在 `lv_conf.h` 中 `LV_FONT_SOURCE_HAN_SANS_SC_*_CJK` 默认被 `lv_conf_internal.h` 置 0，
  此前从未实际编译进固件（原 `hmi_runtime` 二进制中无该字体符号，属死代码）。

## 4. 修复内容

1. **重新生成 14px / 16px Noto CJK 子集**（lv_font_conv 1.5.3）：
   - 字符集 = 2500 常用字 + 中文标点/全角符号 + ▼✓✕▲●◆ 等 UI 符号 + ASCII 0x20-0x7F + FontAwesome 键盘符号。
2. **在 `lv_conf.h` 启用内嵌字体**：`LV_FONT_SOURCE_HAN_SANS_SC_14_CJK=1`、`_16_CJK=1`。
3. **`main.c` 中文回退改为内嵌 Noto 子集**（原为无中文字形的 montserrat），与 `host_main.c` 对齐。
4. 同步到 t113/app、Tina-SDK package/gui/lvgl、build 目录。
