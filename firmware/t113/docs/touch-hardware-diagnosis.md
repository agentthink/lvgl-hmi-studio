# WavePI-S6 触摸屏硬件诊断报告（2026-08-24）

## 结论

**GT911 芯片本身工作正常，但触摸屏感应层未向芯片传递触摸信号。**
这是硬件接触/损坏问题，非软件或固件问题。

## 诊断过程与证据

### 1. 芯片状态（全部正常）
| 检查项 | 结果 |
|--------|------|
| I2C 总线设备 | 0x14 地址响应 ✅ |
| 芯片 ID | "911"（寄存器 0x8140）✅ |
| 固件版本 | 6.0（寄存器 0x8144）✅ |
| 命令寄存器 | 0x8040 可读写 ✅ |
| 配置寄存器 | 0x8047 可读 ✅ |

### 2. 配置正确性
```
分辨率: X=1024, Y=600（寄存器 0x8047: 00 04 58 02）
最大触点: 5
触发方式: 0x3D bit0=1（下降沿触发）
```

### 3. 中断链路（全部正常）
- DTS `ctp_int_port = PD22`（phandle 0x13, bank 3, pin 22）
- PD22 的 EINT = bank 2 × 32 + 22 = **hwirq 86**（/proc/interrupts 显示 PA3_EINT 只是驱动硬编码名称，非真实引脚）
- 驱动 `CTP_IRQ_MODE = IRQF_TRIGGER_FALLING`（下降沿）
- GPIO118 (PD22) 空闲 = 1（高电平），无触摸时无变化

### 4. 决定性证据
卸载驱动后直接轮询 GT911 状态寄存器 0x814E：
```
触摸前/中/后 10 秒: status = 0x00 0x00 （恒为 0，无触摸标志）
```
**芯片完全没有检测到触摸 → 感应层信号未到达芯片**

## 可能原因（按可能性排序）

1. **FPC 排线接触不良**：触摸屏到主板排线松脱、卡扣未锁紧、金手指氧化
2. **触摸屏 ITO 感应层损坏**：透明导电层断裂、玻璃破损
3. **排线损伤**：弯折过度导致内部断线

## 处理建议

1. 断电后重新插拔触摸屏 FPC 排线，确认卡扣锁紧
2. 检查排线金手指是否氧化、排线是否有折痕
3. 换已知正常的触摸屏交叉测试（区分屏 vs 板）
4. 示波器量 INT 引脚：触摸时应有下降沿脉冲

## 已完成的软件修复（保留备用）

- DTS: ctp@14 配置正确（0x14 地址, PD22 中断, 1024×600）
- runtime_config.h: HMI_TOUCH_DEV=event2（GT911 电容屏）
- main.c: 字体回退修复（FreeType 完整 CJK 字体）
