# AI 助手界面基础图形样式规范（v1.0）

> 适用范围：AI 助手面板（`AiChatPanelView`）、AI 图片/图标生成对话框（`AiIconDialog`）及后续 AI 相关界面。
> 目标：统一按钮、开关按钮、复选框、单选、输入框、滑块、下拉菜单等常见控件的**背景图/背景样式**，四态（默认/悬停/按下/禁用）一致、可直接用于前端实现并统一维护。
> 底层依据：本规范全部色值均取自项目唯一颜色源 —— `App.axaml` 全局 token（`Hmi*` 系列）与 `HmiEditor.Core.Design.PaletteDefaults`，**禁止在界面层新增裸 hex**。所有值可直接映射到 Avalonia XAML / 代码生成器 C 输出。

---

## 0. 设计原则与全局参数

| 原则 | 说明 |
|---|---|
| 深色底座 | 界面固定 `RequestedThemeVariant="Dark"`，窗口底色 `#131c31`（HmiBgWindow） |
| 单一颜色源 | 色值只允许引用 `Hmi*` token 或本规范派生的四态色（见各节）；改动只需改 `App.axaml` |
| 扁平 + 低阴影 | 控件本体扁平（无默认阴影），仅滑钮/弹出层用轻投影提升层级 |
| 状态过渡 | 背景/边框颜色切换统一 `BrushTransition` 0.15s，禁止生硬跳变 |
| 无边框按钮 | 按钮一律 `BorderThickness="0"`，用色块表达语义，不画外框 |
| 禁用态全局规则 | 任何控件禁用 = **整体透明度 40%**（`Opacity="0.4"`）+ 文字降为 `#64748b`，不单独重画背景 |

### 0.1 圆角体系（CornerRadius）

| 层级 | 值 | 用途 |
|---|---|---|
| S 微圆角 | 3 | RepeatButton 箭头、步骤轨迹卡（AI 面板步骤框） |
| M 控件圆角 | 4 | 按钮、输入框、下拉、复选、消息气泡（`HmiBgInput` 卡） |
| L 弹出圆角 | 8 | 下拉弹出面板、右键菜单、ToolTip 面板 |
| XL 窗口圆角 | 10 | 子窗口外壳（`HmiWindowCornerRadius`），标题栏上圆角 `10,10,0,0` |
| 胶囊 | 高度/2 | 开关轨道、滑块端点、标签芯片 |

### 0.2 尺寸基准

| 场景 | 最小高度 | 字号 | 内边距 |
|---|---|---|---|
| 超小按钮（消息内操作） | 22–24 | 11 | `10,3` |
| 标准按钮 / 输入 / 下拉 | 28–32 | 12 | `12,4` ~ `16,6` |
| 对话框主操作按钮 | 32 | 12–13 | `16,6` |
| 输入框（多行描述） | 56–120 | 12–13 | 见输入框节 |

## 1. 普通按钮（Button）

### 1.1 背景图设计要点
- 纯色块 + 圆角 4，**无边框**（`BorderThickness=0`）、无背景图纹理；语义靠底色区分。
- 文字一律 `#e2e8f0`（HmiTextPrimary），保证深底高对比。
- 语义分五档，按下态比默认**加深一档**、悬停**提亮一档**（透明度不变，改色相亮度）。

### 1.2 四态配色矩阵（背景色 hex）

| 变体 | 默认 | 悬停 | 按下 | 禁用 | 适用场景 |
|---|---|---|---|---|---|
| **主按钮** Accent | `#2563eb` | `#3b82f6` | `#1d4ed8` | 40% + `#64748b` 文字 | 发送、生成、入库、确认（最高优先级操作） |
| **成功按钮** SuccessDeep | `#065f46` | `#047857` | `#064e3b` | 同上 | 应用改动、保存 PNG、执行成功类操作 |
| **中性按钮** NeutralDeep | `#4b5563` | `#6b7280` | `#374151` | 同上 | 取消、关闭、跳过 |
| **危险按钮** DangerDeep | `#4a1c1c` | `#7f1d1d` | `#450a0a` | 同上 | 回滚、删除、不可逆操作 |
| **次级按钮** BgSelected | `#1e3a5f` | `#24487a` | `#18304e` | 同上 | 预览、保存 SVG、面板内次要动作 |

### 1.3 参数汇总

| 参数 | 值 |
|---|---|
| 圆角 | 4 |
| 边框 | 无（`BorderThickness=0`） |
| 阴影 | 无（扁平）；仅当按钮浮于卡片上时可用 `0 1px 2px rgba(0,0,0,.35)` 提层级 |
| 过渡 | 背景 `BrushTransition` 0.15s |
| 最小宽度 | 常规 ≥ 64px；图标按钮 28×28（圆角 4） |

## 2. 开关按钮（ToggleButton / ToggleSwitch）

> 项目存在两类"开关"：**段选择 ToggleButton**（图标/图片模式切换）与**滑动开关 ToggleSwitch**（Agent 模式等布尔开关）。两者规范不同，分别给出；其中滑动开关另见 §2.3 两态背景图专题。

### 2.1 段选择 ToggleButton（成组互斥）
| 状态 | 背景 | 前景 | 边框 |
|---|---|---|---|
| 未选中 | `#1e293b`（HmiBgElevated） | `#94a3b8`（HmiTextSecondary） | 无 |
| 选中 | `#1e3a5f`（HmiBgSelected） | `#e2e8f0`（HmiTextPrimary） | 无 |
| 悬停（未选中） | `#24487a` | `#e2e8f0` | 无 |
| 按下 | `#18304e` | `#e2e8f0` | 无 |
| 禁用 | 40% 透明度 | `#64748b` | 无 |

- 圆角 4，`Padding 12,4`，字号 12；成组时按钮间距 6px。
- 选中态必须与未选中态**同时存在视觉对比**：色相（蓝 vs 灰）+ 文字亮度双重差异，不依赖单一方块。

### 2.2 滑动开关 ToggleSwitch（轨道 + 滑钮）
| 部件 | 关闭（Off） | 开启（On） |
|---|---|---|
| **轨道背景图** | `#334155`（HmiInputBorder，可叠 60% 透明度） | `#2563eb`（HmiAccentHover） |
| **滑钮背景图** | `#c8d2e1`（OffKnob） | `#ffffff` |
| 滑钮位置 | 左端（距左缘 2px） | 右端（距右缘 2px） |
| 轨道悬停 | `#475569` | `#3b82f6` |
| 禁用 | 整体 40% 透明度 | 整体 40% 透明度 |

### 2.3 开关两态背景图方案（专题）

**图形构成**：背景图 = 胶囊轨道 + 圆形滑钮，两态共用同一尺寸，仅换色 + 平移。

```
关闭（Off）                        开启（On）
┌──────────────────┐              ┌──────────────────┐
│  ████████████████ │  ← 轨道      │  ████████████████ │  ← 轨道
│    ○              │  ← 滑钮(左)  │              ●    │  ← 滑钮(右)
└──────────────────┘              └──────────────────┘
轨道 #334155                      轨道 #2563eb
滑钮 #c8d2e1                      滑钮 #ffffff
```

**尺寸规格**（推荐 40×20 标准型，可等比缩放）：

| 参数 | 值 | 说明 |
|---|---|---|
| 轨道尺寸 | 40 × 20 | 宽:高 = 2:1 |
| 轨道圆角 | 10 | 高度/2，胶囊 |
| 滑钮直径 | 16 | 轨道高 20 − 内边距 2×2 |
| 滑钮圆角 | 8（正圆） | 直径/2 |
| 滑钮内边距 | 2 | 轨道边缘 → 滑钮边缘 |
| 滑钮 X（关） | 2 | 左端贴边 |
| 滑钮 X（开） | 22 | = 40 − 16 − 2，右端贴边 |
| 切换动画 | 0.15s | 滑钮 `TranslateTransform.X` 从 0 → 20（或直接平移 20px）+ 轨道色 `BrushTransition` |

**状态切换视觉差异清单**：
1. **颜色**：轨道 `#334155`（冷灰）→ `#2563eb`（品牌蓝），色相与明度同时改变，色盲可辨（非仅红绿）。
2. **滑钮位置**：左端（x=2）→ 右端（x=22），平移 20px，0.15s 平滑。
3. **滑钮亮度**：`#c8d2e1` → `#ffffff`，开启时更亮，与蓝色轨道形成高对比。
4. **可选增强**：开启态滑钮内可加 8px 白色圆点或轨道上加"✓"（`#ffffff`，10px），关闭态留空；图标为可选项，颜色+位置变化已是充分信号。

**适用场景**：Agent 模式开关、自动执行开关、任何布尔配置项；段选择用 §2.1 的 ToggleButton，二态实体开关用本节。

## 3. 复选框（CheckBox）

### 3.1 背景图设计要点
- 选框 16×16 方块 + 圆角 4；对勾用矢量 path 或字形，不依赖位图。
- 未勾选 = 深底 + 描边（内凹感）；勾选 = 品牌蓝实底 + 白色对勾（外凸强调）。

### 3.2 四态参数

| 状态 | 选框背景 | 选框边框 | 对勾 | 说明 |
|---|---|---|---|---|
| 默认（未勾） | `#1e283c`（CheckBoxOff） | `#334155` 1px | — | 无对勾 |
| 悬停（未勾） | `#1e283c` | `#3b82f6` 1px | — | 仅描边亮起，提示可点 |
| 按下 | `#1d4ed8` | `#2563eb` 1px | 半透明 | 反馈按压 |
| 勾选 | `#2563eb` | `#2563eb` 1px | `#ffffff` | 实底 + 对勾 |
| 禁用 | 整体 40% 透明度 | — | 同左 | 全局禁用规则 |

- 字号 12，文本色 `#e2e8f0`；文本与选框间距 6px。
- 过渡：背景 + 边框 0.15s。

## 4. 单选（RadioButton）

### 4.1 背景图设计要点
- 外圈 18×18 正圆（描边式），选中时内部出现 8px 实心圆点；空心 ↔ 实心表达状态。
- 与复选框区分：**圆形 + 中心点**，不与其他控件混用。

### 4.2 四态参数

| 状态 | 外圈 | 内点 | 说明 |
|---|---|---|---|
| 默认（未选） | `#334155` 1.5px | 无 | 空心圈 |
| 悬停（未选） | `#3b82f6` 1.5px | 无 | 描边亮起 |
| 按下 | `#1d4ed8` 1.5px | 半透明 6px | 反馈按压 |
| 选中 | `#2563eb` 1.5px | `#e2e8f0` 8px | 蓝圈 + 亮心 |
| 禁用 | 整体 40% 透明度 | — | 全局禁用规则 |

- 字号 12，文本色 `#e2e8f0`；过渡 0.15s。

## 5. 输入框（TextBox / NumericUpDown）

### 5.1 背景图设计要点
- 面板内输入框背景 `#1a2332`（HmiBgPanel），独立对话框内 `#151e30`（HmiBgInput）；统一边框 `#334155` 1px。
- 聚焦是最重要状态：边框切换品牌蓝 + 加粗到 1.5px（可叠加外发光 `0 0 0 3px rgba(59,130,246,.25)`）。
- 占位符文字 `#7c8aa0`（HmiTextHint），正文 `#e2e8f0`。

### 5.2 四态参数

| 状态 | 背景 | 边框 | 文字/占位 |
|---|---|---|---|
| 默认 | `#151e30` / `#1a2332` | `#334155` 1px | 正文 `#e2e8f0` / 占位 `#7c8aa0` |
| 悬停 | 同默认 | `#4b5e82` 1px | 同默认 |
| 聚焦 | 同默认 | `#3b82f6` **1.5px** | 同默认 |
| 禁用 | `#111827` + 40% 透明度 | `#334155` | `#64748b` |

### 5.3 参数汇总

| 参数 | 值 |
|---|---|
| 圆角 | 4（NumericUpDown 亦为 4） |
| 最小高度 | 单行 28；多行描述 56–120（`MinHeight=56, MaxHeight=120`, `AcceptsReturn=True`, `TextWrapping=Wrap`） |
| 内边距 | 单行 `8,4`；多行 `8,6` |
| 聚焦外发光 | `0 0 0 3px rgba(59,130,246,.25)`（可选，提升可发现性） |
| 过渡 | 边框 0.15s |

## 6. 滑块（Slider）

### 6.1 背景图设计要点
- **轨道**：4px 高横条，圆角 2，底色 `#334155`；**已填充段**叠在轨道上，用品牌蓝。
- **滑钮**：20×20 正圆，唯一允许带阴影的控件部件（投影提示可拖动）。
- 与 LVGL 目标运行时一致：指示色即主色，轨道未设色时透明兜底 `#334155`。

### 6.2 四态参数

| 状态 | 轨道 | 已填充段 | 滑钮 |
|---|---|---|---|
| 默认 | `#334155` | `#2563eb` | `#e2e8f0`，阴影 `0 2px 4px rgba(0,0,0,.4)` |
| 悬停 | `#475569` | `#3b82f6` | `#ffffff` |
| 按下 | `#334155` | `#1d4ed8` | `#3b82f6` |
| 禁用 | 整体 40% 透明度 | 同左 | 同左 |

- 滑钮直径 20、轨道高 4；滑钮圆角 10（正圆）；拖拽命中区 ≥ 24×24（无障碍）。
- 适用场景：参数调节（尺寸、透明度、阈值），在 AI 界面中用于连续量输入。

## 7. 下拉菜单（ComboBox）

### 7.1 背景图设计要点
- 外观与输入框同构（高 28、圆角 4、边框 `#334155` 1px、背景 `#1a2332`），保证表单行视觉对齐。
- 弹出面板是独立层：`#1a2332` 底 + `#2a3a55` 1px 边框 + 圆角 8 + `Padding 4`（与 ContextMenu 规范一致）。
- 下拉箭头 `#94a3b8`、12px，悬停/展开时转 `#3b82f6`。

### 7.2 四态参数

| 状态 | 控件背景 | 边框 | 弹出面板 |
|---|---|---|---|
| 默认 | `#1a2332` | `#334155` 1px | 见下 |
| 悬停 | 同默认 | `#4b5e82` 1px | — |
| 聚焦/展开 | 同默认 | `#3b82f6` 1.5px | 出现 |
| 禁用 | 40% 透明度 | `#334155` | 不弹出 |

**弹出面板参数**：背景 `#1a2332`、边框 `#2a3a55` 1px、圆角 8、Padding 4、阴影 `0 4px 12px rgba(0,0,0,.4)`；选项行高 28、圆角 4、内边距 `10,5`；悬停/选中行背景 `#1e3a5f`（HmiBgSelected），文字 `#e2e8f0`；禁用项文字 `#64748b`。

## 9. 维护约定

1. **改色只改 `App.axaml`**（与 `PaletteDefaults` 同步），界面层与生成器一律引用 token/常量，禁止裸 hex。
2. **四态色以本规范 §1.2、§5.2 等矩阵为准**，新增控件先查表，勿另造派生色。
3. **禁用态不新画**：统一 `Opacity=0.4` + 文字 `#64748b`。
4. **状态过渡统一 0.15s** `BrushTransition`（按钮另加 BorderBrush 过渡）。
5. 代码生成器（C 输出）中按钮/开关/滑块等的固件配色同样引用 `PaletteDefaults` 派生，与编辑器预览一致。

## 10. 落地状态（v1.1，2026-08-15）

本规范已落地为 `App.axaml` 全局资源，可直接使用：

| 规范条目 | 落地形式 |
|---|---|
| §1.2 五档语义按钮 | 类样式 `Button.primary / .success / .neutral / .danger / .secondary`，含 `:pointerover / :pressed / :disabled` 四态 |
| §2.1 段选择 ToggleButton | 全局 `ToggleButton` 样式（含 `:checked` 选中蓝底、悬停/按下/禁用） |
| §2.2/§2.3 滑动开关 | 全局 `ToggleSwitch` 样式：`Background`=轨道、`Foreground`=滑钮，关态 `#334155`+`#c8d2e1`，开态 `#2563eb`+`#ffffff`，0.15s 过渡 |
| §3 复选框 | 全局 `CheckBox` 样式（未勾深底描边 / 勾选蓝底、悬停描边亮起） |
| §4 单选 | 全局 `RadioButton` 样式（空心→蓝圈亮心） |
| §5 输入框 | 全局 `TextBox` 样式补齐 `:pointerover`（边框 `#4b5e82`），聚焦蓝 1.5px |
| §6 滑块 | 全局 `Slider` 样式（轨道=Background、填充+滑钮=Foreground 品牌蓝） |
| §7 下拉 | 全局 `ComboBox` 样式补齐悬停/聚焦加粗；`ComboBoxItem` 行高 28、悬停/选中 `#1e3a5f` |

**新增 token（App.axaml，界面层禁裸 hex）**：`HmiBtnAccentPressed`、`HmiBtnSuccessHover/Pressed`、`HmiBtnNeutralHover/Pressed`、`HmiBtnDangerHover/Pressed`、`HmiBtnSecondaryHover/Pressed`、`HmiCheckOff`（=PaletteDefaults.CheckBoxOff）、`HmiInputBorderHover`、`HmiTrackHover`、`HmiKnobOff`（=PaletteDefaults.OffKnob）、`HmiKnobOn`。

**用法示例**：
```xml
<Button Classes="primary" Content="生成"/>
<Button Classes="secondary" Content="保存 SVG"/>
<Button Classes="danger" Content="删除"/>
<ToggleSwitch IsChecked="{Binding AutoRun}"/>
<CheckBox Content="启用告警"/>
<RadioButton Content="串口" IsChecked="True"/>
<Slider Minimum="0" Maximum="100"/>
```

> 注：`AiIconDialog` 的模式切换按钮由 code-behind 显式设置背景（本地值优先于样式），视觉与本规范一致，无需改动。
