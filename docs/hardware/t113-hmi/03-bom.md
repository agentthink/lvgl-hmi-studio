## 6. 采购与贴装注意事项

1. **T113-S3**：立创商城 C5197687 现货且支持嘉立创 SMT 扩展库贴装，是首选的量产渠道；也可通过全志授权代理（如米尔/盈鹏飞等模组商）购买整板验证后再自研。
2. **嘉立创 SMT**：下单时勾选「SMT 贴装」，扩展库物料会自动在钢网/贴装计划中处理；手焊件（端子、DB9、FPC 座）可发嘉立创 DIP 焊接或自行焊接。
3. **可替代性**：PHY（IP101GRI/LAN8720A）、RS485（MAX3485/SP3485）、RS232（MAX3232/SP3232）、背光驱动（MT9284/SY7208/PT4103）均有多货源，替换时同步核对引脚与驱动配置。
4. **库存检查**：批量采购前在立创商城确认每颗料的可供货量与交期，长周期件（SoC、PHY）建议提前 4~8 周下单。
5. **BOM 导出**：LCEDA 原理图完成后用「BOM 清单」导出 CSV，与本文档逐项比对（值/封装/数量），再导入立创商城购物车或批量报价。
