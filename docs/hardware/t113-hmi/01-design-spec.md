## 1. 项目概述

本项目设计一款面向工业自动化场景的 **HMI（人机交互）主板**，以全志 **T113-S3**（双核 ARM Cortex-A7 @1.2GHz，内置 128MB DDR3）为核心，配套 800×480 / 1024×600 RGB 液晶屏与电阻触摸屏，提供多路工业串口、以太网、USB 及无线扩展能力，可直接用于原型制作与批量生产。

设计在 LCEDA（嘉立创 EDA 专业版）平台上实施，目标工厂为嘉立创（PCB 打样 + SMT 贴片 + 立创商城物料），核心器件选用立创商城在售/嘉立创 SMT 可贴装型号。

## 2. 需求规格

### 2.1 接口配置（用户确认）

| 序号 | 接口 | 规格 | 说明 |
| --- | --- | --- | --- |
| 1 | COM1（DB9） | **RS232 / RS485 双协议可切换**，RS485 带**电气隔离** | 接 UART2；协议切换 GPIO + 拨码开关 |
| 2 | RS485-1 | 半双工，速率≤1Mbps，**电气隔离** | 接 UART3（现有固件 Modbus RTU 默认口，ttyS3 不变） |
| 3 | 以太网 ×1 | 10/100M RMII | 独立 PHY（IP101GRI）+ 带变压器 RJ45 |
| 4 | USB Host ×1 | USB2.0 480Mbps | USB-A 接口，带 VBUS 开关与 ESD |
| 5 | Type-C ×1 | USB2.0 OTG（USB0） | 下载/OTA 用，不再承担系统供电 |
| 6 | 液晶接口 | **50PIN RGB888**，已选 **7″ 1024×600 IPS（SZCLX070H-500-IPS-G-RTP）**，备选 10″ 1024×600 | 含背光供电/调光、面板偏压（AVDD/VGH/VGL/VCOM） |
| 7 | 电阻触摸接口 | 4 线，T113 内置 TPADC | 无需外部触摸控制器；坐标按面板分辨率校准 |
| 8 | 无线扩展（预留） | SDIO（WiFi）+ USB（4G/5G 模块） | 2.54mm 双排针引出 |
| 9 | 状态指示灯 | **双色 LED**（红/绿） | 复用现有固件 ledc GPIO 引脚 |
| 10 | 电源输入 | **12~24V DC 宽压** | 反接保护 + 浪涌 TVS + LC 滤波，降压 5V 系统电源 |

### 2.2 结构要求

- **所有外接接口（连接器）集中排布在 PCB 同一长边**（I/O 边），便于后期安装外壳时开孔、出线。
- 板载调试、供电、按键等调试类接口可布局在其余边缘/板内。

### 2.3 固件兼容性要求（与 `firmware/t113/` 现有代码保持一致）

| 固件资源 | 硬件要求 | 本设计满足方式 |
| --- | --- | --- |
| `modbus_rtu.c` 默认 RS485 | `/dev/ttyS3`（UART3，PG8/PG9） | RS485-1 固定接 UART3，**带电气隔离** |
| COM1 双协议 | UART2（PE2/PE3）+ 模式 GPIO | 协议切换由 `set_serial.c` 设置界面通过 GPIO 控制（拨码可硬件强制） |
| 调试串口 | UART1（PG6/PG7）115200 | 板载 4P 调试排针 |
| 背光 PWM | PWM2 | 背光驱动芯片 PWM 调光脚 |
| 状态灯（`gpio_sunxi.c`） | LEDC GPIO（PE0/PE1/PE8/PE9） | PE0=红、PE1=绿（双色灯） |
| 触摸 evdev | 电阻触摸 `/dev/input/event0`（内核 TPADC 驱动） | TPADC 直连 4 线电阻屏；`HMI_TOUCH_MAX_X/Y` 按面板分辨率校准 |
| 网络 | `eth0`（RMII） | PG 组 EMAC + IP101GRI |
| 存储启动 | SPI NAND 启动 | SPI0 + W25N01GV（128MB） |
| OTA（`hmi_ota.sh`） | TF / USB / 网络 三通道 | USB（Type-C）与网络通道原生支持；TF 卡座预留（DNP） |
| 双分辨率显示 | 内核 DTS `lcd0` 节点 + 编辑器自适应 | 7″/10″ 均为 1024×600（同时序），仅背光 Rcs/偏压按屏微调；编辑器 `AdaptiveLayoutCalculator`/`ScreenAdaptiveMode` 输出自适应布局 |

### 3.2 关键选型依据

- **T113-S3**：eLQFP128（14×14mm）四边引脚封装，**无需外部 DDR 布线**，PCB 设计与生产难度大幅降低；内置 128MB DDR3（800MHz），满足 LVGL 界面 + Linux 运行需求；内置 4 路 TPADC 可直接采集 4 线电阻触摸，省去外部触摸控制器。
- **立创生态**：SoC 在立创商城有现货（C5197687，嘉立创 SMT 扩展库支持），配套器件均可从立创商城采购，支持嘉立创 SMT 一站式贴片，适合原型与量产。
- **电源分立方案**：3 路 Buck + 1 路 LDO，无 PMIC，供应链简单、成本低、易维修，与多份开源 T113 量产板验证一致。

## 5. 外壳与单边接口布局

所有外接连接器位于 **130mm 长边（I/O 边）**，自左至右建议排布：

| 位置 | 连接器 | 备注 |
| --- | --- | --- |
| ① | RS485-1（3P 5.08mm 端子，A/B/GND） | **隔离**（Modbus 默认口） |
| ② | 预留扩展位 | 可加装第二串口端子（DNP） |
| ③ | COM1 DB9（RS232/RS485 可切换） | 隔离 RS485 通道，拨码+GPIO 切换 |
| ④ | RJ45（HR911105A，带变压器） | PHY 靠近此位置 |
| ⑤ | USB-A（USB1 Host） | |
| ⑥ | Type-C（USB0 OTG） | 下载/OTA，不承担系统供电 |
| ⑦ | LCD 50PIN FPC（0.5mm，RGB888+背光+触摸） | 板内驱动靠近此位置；兼容 7″/10″ 面板 |
| ⑧ | 无线扩展（2.54mm 2×6 排针：SDIO1 + USB + 电源） | 5G 模块用 USB |
| ⑨ | 12~24V 电源端子（2P 5.08mm） | 主供电，宽压输入 |

调试类（不占 I/O 边）：调试串口 4P 排针、按键（复位/FEL/用户）、双色状态 LED（建议布置在 LCD 同侧以便前面板可视）、JTAG（可选）。

## 6. 电源架构概要

```
12~24V DC ──► 反接保护(P-MOS) ──► 保险丝 ──► TVS(SMCJ24A) ──► LC 滤波
        ──► MP1584EN 宽压降压 ──► 5V_SYS（3A）
5V_SYS
 ├─► SY8089A1AAC  3.3V / 2A   ──► VCC_IO、SPI NAND、PHY、串口、LCD 逻辑
 │     └─► ME6211A18  1.8V / 0.5A ──► VCC_PLL、AVCC、EFUSE、RTC 域
 ├─► SY8089A1AAC  0.9V / 2A   ──► VCC_CPU（内核）
 ├─► SY8088AAC    1.5V / 1A   ──► VCC_DRAM（内置 DDR3）
 ├─► B0505S 隔离电源 ×2（RS485-1 与 COM1 RS485 通道）
 └─► 5V 直供：USB1 VBUS 开关、LCD 背光 Boost
上电时序：3V3 → 0.9V → 1.5V（DRAM 严禁先于核心上电，否则 DDR 初始化失败）
```

> 详细电路（反馈电阻、电感、电容阵列、使能链）见 `02-schematic-spec.md` 第 3 节。
