# T113-S3 HMI 主板 PCB 布局与 EMC 设计指南

> 文档版本：V1.0　|　日期：2026-08-10
> 配套：`02-schematic-spec.md`（原理图）、`03-bom.md`（物料）。本文件覆盖叠层、阻抗、布局分区、布线规则、电源完整性、EMC、散热与生产工艺。

---

## 1. 叠层设计

T113-S3 为 eLQFP128（四边引脚）且 DDR3 内置（**无外部 DDR 布线**），本设计 **4 层板即可满足**，成本最优；若量产追求更优 EMC/信号质量可升级 6 层。

### 1.1 4 层推荐叠层（板厚 1.6mm，铜厚 1oz）

| 层 | 名称 | 用途 |
| --- | --- | --- |
| L1 | TOP | 主信号 + 元件（SoC、接口、去耦） |
| L2 | GND | **完整地平面**（严禁分割） |
| L3 | PWR | 电源分割层（5V_SYS/3V3/1V8/1V5/0V9） |
| L4 | BOTTOM | 次信号 + 元件（电阻电容、接口背面） |

- 板材：FR4 TG150+（工业要求），备选 TG170。
- 阻抗控制：表层单端 **50Ω**、差分 **90Ω**（USB），差分线宽 6mil/间距 8mil（依厂家参数微调）。

### 1.2 6 层可选叠层

L1 信号 / L2 GND / L3 电源 / L4 信号 / L5 GND / L6 信号 —— 双完整地平面，EMC 裕量更高。

## 2. 布局分区（关键：I/O 单边布局）

板卡 **130mm × 100mm**，四角 M3 安装孔。外接连接器全部位于 **130mm 长边（I/O 边）**，自左至右：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  ┌──────┐┌────┐┌───┐┌────┐┌────┐┌──────┐┌──────────────┐┌──────────┐┌────┐ │
│  │RS485-1│预留 │DB9 │ RJ45│USB-A│Type-C│  LCD 50P FPC │ 无线排针  │12~24V│ │
│  └──────┘└────┘└───┘└────┘└────┘└──────┘└──────────────┘└──────────┘└────┘ │
│     ①      ②    ③     ④    ⑤     ⑥        ⑦            ⑧        ⑨      │
├─────────────────────────────────────────────────────────────────────────────┤
│  左上：宽压电源区（MP1584EN+反接保护+TVS）       中部：T113-S3+去耦+SPI NAND │
│  左下：隔离区（B0505S×2+ADUM1201×2，ISO_GND 净空区） 右下：PHY+RJ45         │
│  右上：LCD 背光+触摸接口                             板内：调试排针/按键/LED │
│  注：隔离栅（GND/ISO_GND 分割线）贯穿板内，两侧器件互不跨越                │
└─────────────────────────────────────────────────────────────────────────────┘
```

**分区原则：**
1. **宽压电源区独立**：MP1584EN 输入/输出/电感、反接保护 P-MOS、TVS、保险丝集中，与数字区物理隔离；**高压输入（12~24V）走线与低压走线间距 ≥ 0.5mm（安规）**；功率地 PGND 单点连 GND。
2. **SoC 居中**：T113 位于板中部偏上，四周留走线通道；去耦电容紧贴电源引脚（< 3mm）。
3. **PHY 靠近 RJ45**：RMII 走线最短化；变压器（RJ45 内置）与 PHY 间差分对不跨分割。
4. **接口按单边排布**：每个连接器内侧先放 ESD/TVS 器件（< 5mm），再接主信号。
5. **隔离区（关键）**：B0505S 与 ADUM1201 集中放置，**GND 与 ISO_GND 之间留净空分割带（≥ 2mm），隔离器件本体下方不得有铜/走线**；两侧信号（TX/RX）在隔离器件处截止，不得旁路。
6. **背光 Boost 与面板偏压远离敏感信号**：U12（~10V/200mA 开关节点）与 U13（TPS65100 的 18V/-6V 高压节点）靠近 FPC 输出与 LCD 区，不穿越 SoC 下方；高压走线（VGH 18V）与低压间距 ≥ 0.5mm（安规）。
7. **LED 面向前面板**：双色状态灯布置在 LCD 同侧板边（I/O 边对面），便于开窗显示。

## 3. 关键布线规则

### 3.1 电源
| 网络 | 线宽/铜宽 | 过孔 |
| --- | --- | --- |
| 12~24V_IN（高压输入） | ≥ 60mil，与其他走线间距 ≥ 0.5mm（安规） | 2×0.3mm/焊点 |
| 5V_SYS | ≥ 60mil（或铺铜） | 2×0.3mm/焊点 |
| 3V3 / 0V9_CORE / 1V5_DRAM | ≥ 40mil（按 2A） | 多过孔并联 |
| Buck SW 节点 | 短、宽、远离反馈 | 反馈走线单独取输出端 |
| 1V8 | ≥ 20mil | 常规 |
| ISO_5V（隔离侧） | ≥ 30mil，仅存在于 ISO_GND 区域 | 常规 |

- 反馈电阻分压点直接从输出电容端取，避免经电感/开关噪声。
- 各电源分割区在其下方层有完整回流路径，分割线不跨任何高速信号。
- MP1584EN：SW 环路（输入电容→IC→电感→输出电容）面积最小化；输入电解电容紧贴 U1。

### 3.2 高速/关键信号
| 信号 | 规则 |
| --- | --- |
| USB0/USB1 DP/DM | 差分对 90Ω，等长±5mil，包地，串阻（0Ω/22Ω）靠近 SoC |
| EMAC RMII | 单端 50Ω；PG0-PG5/PG12/PG13 等长 ±10mil，REF_CLK 独立走线包地 |
| RGB LCD 数据/控制 | 数据组 D0-D7/D8-D15/D16-D23 组内等长 ±10mil；CLK 与 DE/HS/VS 等长 ±20mil；总长控制 ≤ 2000mil 并远离电源 |
| SPI0（NAND） | CLK 短（≤ 800mil），MOSI/MISO 等长；NAND 靠近 SoC |
| SDIO1（无线预留） | CLK/CMD/D0-D3 等长 ±25mil，D0-D3 包地 |
| TPADC 触摸 | 4 线短走线、加 0Ω 调试位；远离数字高频（干扰会导致触点抖动） |
| 32.768kHz/24MHz 晶振 | 时钟线短（≤300mil），晶振下方挖空/净空，周围包地环，远离高速 |

### 3.3 通用
- 相邻层走线垂直交叉，避免平行长走线。
- 高速信号不跨电源分割槽；必须跨越时下方保持完整地。
- 过孔最小 0.3mm 外径 0.6mm；信号换层就近加地孔。

## 4. 电源完整性（PI）

- 每路电源 10µF 大容量 + 100nF/10nF 高频电容组合，高频电容距引脚 < 3mm。
- VCC_CPU 与 VCC_DRAM 的电容阵列严格按 `02` §3.3 执行——DRAM 供电质量直接决定 DDR3 稳定性与启动成功率。
- 地平面连续：L2 整层 GND 不得开大槽，所有 IC EP 焊盘与地平面多点相连。

## 5. EMC 设计

### 5.1 设计要点
1. **完整地平面**：最有效的基础手段（L2 整层地）。
2. **接口滤波**：所有外接接口内侧就近放置 ESD/TVS（见 `02` §7），连接器金属外壳接机壳地（外壳地与数字地单点/磁珠连接，预留 0Ω 选件）。
3. **电源输入滤波与浪涌**：SMCJ24A TVS 紧贴输入端（< 5mm），P-MOS 反接保护、保险丝、LC 滤波；共模电感 DNP 预留；**高压输入走线与低压走线间距 ≥ 0.5mm，输入电解耐压 ≥ 35V**。
4. **隔离栅（RS485 隔离，关键）**：GND 与 ISO_GND 严格分离，分割带净空 ≥ 2mm；隔离器件本体下方无铜；ISO 侧只允许 RS485 信号与隔离电源，无任何旁路路径。
5. **时钟抑制**：24MHz/32.768kHz 及其走线包地，晶振下方净空；RGB CLK、RMII REF_CLK 尽量短且包地。
6. **开关电源辐射**：Buck 环路面积最小化（输入电容→IC→电感→输出电容环路短、宽）；SW 节点不跨越地平面槽。
7. **机壳屏蔽（量产可选）**：SoC 区/电源区加屏蔽罩，弹簧片接机壳地。

### 5.2 测试预留
- 板上预留 EMC 测试点：各电源轨测试点（0Ω 串位）、机壳地测试点、GND 多点、ISO_GND 测试点。
- 预留共模电感/磁珠 0Ω 替换位（干扰超标时调试用）。

## 6. 散热设计

- **T113-S3 热耗**：典型 1.5~2.5W（CPU 满载），eLQFP128 **EP 散热焊盘必须接地并打热过孔阵列**（0.3mm 孔、1.0mm 间距、覆盖 EP 全区域，贯通至 L2 地平面大面积散热）。
- EP 焊盘焊接：钢网按 EP 面积开 70% 网格开孔，防止虚焊/焊料溢出短路四边引脚。
- **MP1584EN（宽压 Buck）**：24V 输入、3A 满载时损耗约 0.8~1.5W，SOP8 底部焊盘需大面积铺铜散热（顶层+底层过孔阵列）；输入 24V 连续工作时注意周边温度。
- 板内热源分布：SoC（约 2W）与背光 Boost（约 0.5W）、Buck（各 0.2~0.4W）分散布置，避免集中。
- 外壳散热：若密闭塑料外壳，建议 SoC 正上方加导热硅垫+金属散热片（选配）；工业宽温需求下选 TG170 板材。
- 实测建议：原型阶段用热成像验证 SoC 壳温 ≤ 85℃（环境 70℃ 时需留裕量）。

## 7. 生产工艺要求（嘉立创）

| 项目 | 要求 |
| --- | --- |
| PCB 工艺 | FR4，1.6mm，1oz 内外铜，阻焊绿色，沉金（FPC 座/端子焊接可靠性）或喷锡（低成本） |
| 最小线宽/线距 | ≥ 5mil/5mil（差分对 6/8 不受限） |
| 最小孔径 | 0.3mm 机械孔；Via 0.3/0.6 |
| 钢网 | 0.12mm 厚度；T113 EP 网格开孔 70% |
| 拼板 | 量产 V-cut 拼板（如 2×3），留工艺边 + 光学点 |
| 贴装 | 嘉立创 SMT 标准/扩展库；DIP 件（端子/DB9/FPC）可 DIP 焊接 |
| 测试 | 出厂 ICT/飞针：电源短路、上电时序、串口回环、PHY 回环测试位预留 |
| 阻抗 | 如厂家支持，USB 90Ω 差分、50Ω 单端做阻抗测试条（TDR） |

## 8. DRC 清单（LCEDA 内 PCB 检查）

- [ ] 所有网络无未连接引脚；单点网络逐一确认
- [ ] 电源轨线宽满足电流（12~24V_IN/5V_SYS/3V3/0V9 校验；高压输入间距 ≥ 0.5mm）
- [ ] **隔离栅：GND/ISO_GND 分割带 ≥ 2mm 净空，隔离器件下方无铜，无旁路走线**
- [ ] USB 差分对阻抗/等长；RMII、RGB 组等长
- [ ] 去耦电容距引脚 < 3mm；EP 热过孔阵列完成
- [ ] 晶振/时钟走线包地、下方净空
- [ ] 连接器内侧 ESD/TVS 就位（< 5mm）
- [ ] 间距检查（线-孔-铜 > 5mil；元件-板边 > 5mm，I/O 边按外壳开孔需求核对）
- [ ] 安装孔（M3×4）与外壳对位；I/O 连接器与外壳开孔对位
- [ ] 阻焊/丝印：位号可读、方向标记（LED/二极管/极性电容）齐全
- [ ] 生产：Gerber 全层导出、钻孔文件、拼板工艺边、光学点
