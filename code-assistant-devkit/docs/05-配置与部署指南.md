# 05 · 配置与部署指南

## 1. 环境准备

- Python 3.10+（推荐 3.11+，`tomllib` 原生支持）
- 网络可访问 PyPI（首次安装依赖）

## 2. 本地开发部署

```bash
git clone <repo> && cd code-assistant-devkit
./scripts/setup.sh          # 初始化（venv + 依赖 + .env）
./scripts/dev.sh            # 启动 http://127.0.0.1:8000
```

## 3. 生产部署

### 3.1 基础配置

```bash
# .env（生产示例）
DEVKIT_HOST=0.0.0.0
DEVKIT_PORT=8000
DEVKIT_API_KEYS=$(openssl rand -hex 32),$(openssl rand -hex 32)   # 强随机密钥，至少两个便于轮换
DEVKIT_WORK_DIR=/var/lib/devkit
DEVKIT_LOG_LEVEL=INFO
```

### 3.2 systemd 服务（Linux）

`/etc/systemd/system/devkit.service`：

```ini
[Unit]
Description=Code Assistant DevKit Services
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/code-assistant-devkit
EnvironmentFile=/opt/code-assistant-devkit/.env
ExecStart=/opt/code-assistant-devkit/.venv/bin/uvicorn services.api.main:app --host ${DEVKIT_HOST} --port ${DEVKIT_PORT}
Restart=on-failure
RestartSec=3
User=devkit

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now devkit
sudo systemctl status devkit
```

### 3.3 Docker 部署

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
ENV DEVKIT_HOST=0.0.0.0 DEVKIT_PORT=8000
EXPOSE 8000
CMD ["uvicorn", "services.api.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

```bash
docker build -t devkit .
docker run -d --name devkit -p 8000:8000 \
  -e DEVKIT_API_KEYS="$(openssl rand -hex 32)" \
  -v /var/lib/devkit:/app/.runtime \
  devkit
```

### 3.4 Nginx 反向代理（HTTPS）

```nginx
server {
    listen 443 ssl;
    server_name devkit.example.com;
    ssl_certificate     /etc/nginx/ssl/devkit.crt;
    ssl_certificate_key /etc/nginx/ssl/devkit.key;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 4. 安全加固建议

| 项 | 建议 |
| --- | --- |
| 密钥 | 生产使用 `openssl rand -hex 32` 生成，禁用默认开发密钥；支持多个密钥便于轮换 |
| 网络 | 服务绑定内网或经 Nginx 暴露，端口不直接对外 |
| 传输 | 全站 HTTPS（TLS 1.2+） |
| 鉴权升级 | 需要更细粒度权限时，将 `auth.py` 的 `require_api_key` 替换为 JWT 校验（路由无需改动） |
| 部署目录 | `DEVKIT_WORK_DIR` 使用独立挂载卷，定时备份 `releases/` 与 `builds/` |
| 日志 | `logs/app.log` 为 JSON Lines，可直接接入 Loki/ELK 等集中式日志 |

## 5. 运维手册

| 操作 | 命令 |
| --- | --- |
| 健康检查 | `curl -s http://127.0.0.1:8000/health` |
| 查看最近日志 | `curl -s "http://127.0.0.1:8000/api/v1/logs/tail?lines=50" -H "X-API-Key: $KEY"` |
| 回滚发布 | `curl -s -X POST http://127.0.0.1:8000/api/v1/deploy/rollback -H "X-API-Key: $KEY" -d '{"env":"staging"}'` |
| 查看部署历史 | `curl -s "http://127.0.0.1:8000/api/v1/deploy/list/all?env=staging" -H "X-API-Key: $KEY"` |
| 全量测试 | `make test` |
| 端到端演示 | `make demo` |

## 6. 目录与数据约定

```
.runtime/                  # DEVKIT_WORK_DIR（gitignore）
├── builds/                # 构建产物 tar.gz + builds.json（构建档案）
│   └── <name>-<version>.tar.gz
├── releases/              # 部署发布
│   ├── dev/    staging/   prod/          # 按环境分目录
│   │   ├── <version>/                    # 解压后的发布内容
│   │   └── state.json                    # current + history（回滚依据）
└── logs/
    └── app.log            # JSON Lines 日志
```

## 7. 常见问题

- **端口被占用**：修改 `.env` 的 `DEVKIT_PORT` 后重启。
- **`pip install` 慢/失败**：配置国内镜像 `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`。
- **Windows 执行策略**：使用 `powershell -ExecutionPolicy Bypass -File scripts/setup.ps1`。
- **服务返回 401**：确认 `X-API-Key` 在 `DEVKIT_API_KEYS` 中，且请求头名称大小写正确。
